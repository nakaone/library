ena.kaonの税務定期作業は概ね以下のように進める。

  1. 証憑収集、電子化(PDF化)
  2. スプレッドシート上に補足情報を追記
  3. 税理士報告用HTMLの作成

以下、それぞれについて詳述する。

作業のタイミング

税理士側・当方双方の手間を考え、年度初めは3ヶ月おき、だんだん間隔を狭めて年度末は毎月提出。
⇒ 1,4,6,8,9月上旬に実施する。

用語解説

本手順書内で使用する用語の解説。

  • 証憑フォルダ：収集した証憑(PDF)と、管理用スプレッドシートを保存するフォルダ。
    「Google Drive マイドライブ > ena.kaon > log > fy20yy > 電子証憑20yy」
  • 証憑一覧：管理用スプレッドシート。フォルダ直下のGoogle Spread「証憑一覧20yy」。
    「Google Drive マイドライブ > ena.kaon > log > fy20yy > 電子証憑20yy > 証憑管理20yy」
  • backupフォルダ：税理士に提出する必要は無いが、念のため取っておく各種資料の保存場所。 「Google Drive マイドライブ > ena.kaon > log > fy20yy > 電子証憑20yy > backup」

1. 証憑収集、電子化(PDF化)

  • 証憑は全てPDF化して証憑フォルダに保存
  • ファイル名の指定が有る場合、Google Drive上のファイル名はそれに則る

1.1 銀行通帳

  • 前回提出日以降分について、証憑フォルダ内のpdfの末尾に未提出分を追加。
  • ファイル名は「MUFGnn.pdf」 or 「SMBCnn.pdf」(nnは通帳の通番)
  1. 銀行で記帳
  2. 前回提出以降分をスキャン＋PDF化
  3. 証憑フォルダから前回提出時の通帳PDFをダウンロード ※新通帳に切り替えたら新規作成
  4. Macのプレビューで前回分と今回分の両方を開き、差分を前回分に反映
  5. Google Drive上で右ボタンクリック、「ファイル情報 > 版を管理 > 新版をアップロード」を選択、差分反映済の前回分をアップロード

1.2 クレジットカード利用明細(AMEX)

  • 未保存月の利用明細(PDF)をMUFGのサイトからダウンロードし、「電子証憑」フォルダに保存。
  • ファイル名は「20yyMM.pdf」
  • MUFG News+ > ご請求額・利用明細照会
  • ID,PWはGoogle Keepで「MUFGカードWEBサービス」を検索

1.3 EF, CKレントロール

  • TransCreationから送付の都度「電子証憑」のフォルダに保存(ファイルは月単位)。
  • 解凍用のパスワードは ena.Trans-yyyyMMdd (yyyyMMdd = メール送信日)
  • ファイル名は「EF20yyMM.pdf」 or 「CK20yyMM.pdf」

1.4 HSレントロール : 「HS20yyMM.pdf」

  • 確証貼付ノートの所定の位置に確証(定期清掃領収書)と併せて貼付
  • 月単位にスキャンして”HS20yyMM.pdf”を作成、「電子証憑」フォルダに保存

まとめてスキャン後、Macのプレビューでページごとに分割(サムネールをデスクトップにD&D)。 なおA4見開きに貼りきれない証憑は「確証貼付ノート」に貼付する。

1.5 確証貼付ノート

  • ファイル名は「note20yypp.pdf」。「20yy」の部分は会計年度、ppはページ番号。
  1. A4以上のサイズの場合はノート貼付前にスキャン、貼付予定ページ番号を元に”noteYYYYNN.pdf”を作成(YYYYは年度、NNはページ番号)
  2. 確証貼付ノートへの貼付。貼付後、宛先・摘要等必要事項を追記
  3. 1で事前にスキャンしたページ以外について、ページ単位にスキャンして”noteYYYYNN.pdf”を作成
  4. 作成したpdfを証憑フォルダに保存
  5. 確証貼付ノートNo.1の不足時はNo.2を追加するが、ページ番号はNo1,2通しで採番する(No.2の最初のページはNo.1の最終ページ＋1)。

1.6 健保・年金、確定拠出年金

  1. 事前に「確証貼付ノート」の一部を健保・年金用に確保して領収書を貼付。
  2. まとめてスキャン後、Macのプレビューで月ごとに分割(サムネールをデスクトップにD&D)。
  3. ファイル名を”pensionYYYYMM.pdf”に修正して「電子証憑」フォルダに保存

1.7 税理士領収書

  1. GMailを”YFP”で検索して保存。概ね月央(15日前後)にメールで請求書が送られているので証憑フォルダに保存。
  2. ファイル名は”yyyyMMdd_400_xxx.pdf”、xxx: 000->税理士報酬分、003->記帳代行分

1.8 電子証憑

  1. PDFファイルをそのまま保存の上、「証憑管理>記入用」シート上で必要項目を記入
    但し証憑フォルダに同じ名前のファイルが存在する場合、適当に修正する(ほぼあり得ないけど)
  2. 以下は主なもの。MUJI等、不定期に利用した購入先は都度追加する。
    • amazon
    • yodobashi
    • 代行購入(弘子)
    • Apple(ena.kaonのGmail上で「領収書」をキーワードに検索)
    • モノタロウ

1.9 返済明細

  1. 金利の変動が有った場合に銀行から送付される返済予定明細書(払込予定表)。
  2. 返済金額の元金分・利息分は仕訳上「長期借入金」「支払利息」と勘定が異なるため、本明細を基に計上する
  3. ファイル名は「yyyyMMdd_XXXXローン明細書.pdf」とする

1.10 参考資料、その他

  • 収支に関係ないが税理士と共有すべき資料
  • 例：固都税納税通知書、〇〇決定通知書等

2. スプレッドシート上に補足情報を追記

証憑の収集・電子化が終わったら、スプレッドシートと報告書を開く。
以下は何れも2025年度版。2026年度以降は適宜読み替え。

  • スプレッドシート : 証憑フォルダ > 証憑一覧2025
  • 報告書

以下、シート上に必要事項を記入し、適宜報告書(HTML)をリロードして記入事項が反映されているか確認しつつ作業を進める。

「電子証憑」シート

  1. name : 証憑フォルダ内のファイル名
  2. date : 購入年月日
  3. label : 購入品(摘要)
  4. price : 価格
  5. payby : 支払方法
  6. note : 備考

「交通費」シート

  1. date : 日付
  2. dest : 行き先
  3. purpose : 目的
  4. path : 経路
  5. num : 人数
  6. price : 金額
  7. note : 備考

「参考資料」「特記事項」シート

  1. date : 日付
  2. title : タイトル
  3. url : 資料のURL
  4. note : 備考

不要なPDFが紛れていたら

税理士さんに提示が不要な資料が紛れ込んでいた場合、不要なファイルを証憑フォルダからbackupフォルダに移動後、報告書(HTML)をリロードする。

3. 税理士報告用HTMLの作成

3.1 報告用HTMLの作成と保存

  1. スプレッドシートのメニューから「道具箱 > 提出用HTML出力」を選択
  2. 適当なフォルダにダウンロードして内容確認
  3. Google Drive「マイドライブ > share > 税理士法人YFPクレア > log > FY20yy」にアップロード
  4. アップロードしたファイルのURLを税理士に連絡
